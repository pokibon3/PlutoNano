Pluto SDR Nano

Pluto SDR Nano を USB で接続し、Connect を押してデバイスを選択してください。

  • Chrome / Edge が必要です（WebUSB）。
  • スペクトラム / ウォーターフォールをクリックで同調、ドラッグで VFO 移動、ホイールでステップ同調、Ctrl+ホイールでズーム。
  • 周波数表示の桁をホイール / クリックで変更、ダブルクリックで直接入力（MHz）。
